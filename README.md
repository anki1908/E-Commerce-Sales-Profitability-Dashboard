# E-Commerce Sales & Profitability Dashboard — Power BI

An interactive **Power BI dashboard** built to analyze e-commerce sales performance, profitability, customer behavior, and operational metrics.

The project uses **1,000 e-commerce transactions** and demonstrates data cleaning and transformation using **Power Query**, data analysis using **DAX**, and interactive dashboard development in Power BI.

### Key Analysis

* Revenue, profit, tax, and Average Order Value (AOV)
* Monthly sales trends
* Category and product performance
* Top 10 products by revenue and profit
* Regional sales performance
* Sales channel analysis
* Customer segment analysis
* Payment method performance
* Order status, returns, and cancellations
* Customer segment vs. category performance

### Power BI Features Used

* Power Query for data cleaning and transformation
* Calculated columns
* DAX measures
* KPI cards
* Interactive slicers
* Top N analysis
* Matrix and conditional formatting
* Donut, bar, column, and line charts
* Multi-page interactive dashboard
* Page navigation

### Tools & Technologies

**Power BI | Power Query | DAX | Microsoft Excel**
